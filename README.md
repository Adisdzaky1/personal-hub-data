# Ini BUKAN bagian dari repo kode

Folder ini adalah **contoh isi awal untuk repo data GitHub yang terpisah** (lihat
`README.md` di root repo kode, bagian "Menyiapkan Repo Data GitHub").

Upload isi folder `data/` dan `uploads/` di sini ke root repository data kamu
(misal `personal-hub-data`), **bukan** ke repo kode yang di-deploy ke Vercel.

Struktur setelah diupload ke repo data:

```
personal-hub-data/
  data/esp32-projects.json
  data/website-projects.json
  data/blog-posts.json
  data/portofolio.json
  uploads/esp32/
  uploads/website/
  uploads/blog/
  uploads/portofolio/
```

File `.gitkeep` di setiap folder `uploads/*` hanya agar folder kosong ikut
ter-commit ke Git — boleh dihapus setelah ada file sungguhan di dalamnya.
